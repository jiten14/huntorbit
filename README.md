# HuntOrbit

A SaaS product review blog — hands-on reviews, honest verdicts.

🚧 **Status:** Phase 2 complete — full design and 4 launch articles live. Custom domain not yet connected.

## About

Static site built with Jekyll, hosted free on GitHub Pages. No database, no backend, no forms — reviews are written as Markdown files and pushed directly to this repo.

## Stack

- Jekyll (GitHub Pages native build)
- Hosted on GitHub Pages
- Custom domain: huntorbit.com (to be connected after testing)
